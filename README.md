# 诗匣 —— 私人诗歌写作台（两卷）

宣纸底、墨色字、朱砂印。**甲编·新诗** 与 **乙编·古体** 两卷，左上角卷签一点即换，
数据分目录存放在 `../诗匣数据/`，互不干扰；模型配置与设置两卷共享。

- **甲编 · 新诗**：目录点标题进诗、网页改稿（草稿自动暂存、可选留旧版、删版二次确认）、
  稿纸式写新诗、AI 按 100 分制严苛准则评价。
- **乙编 · 古体**：绝句 / 律诗 / 排律 / 古风·乐府 / 诗经体 / 词。写作时右侧格律面板实时检视：
  逐字平仄（含入声标注）、韵脚韵部、粘对、孤平、三平尾、出韵、首句借邻韵（孤雁出群）、
  特拗与拗救识别；词按谱逐句对照（817 调 2475 体，据《钦定词谱》类数据整理）。
  四套韵书随时切换：平水韵（默认）/ 词林正韵 / 中华通韵 / 中华新韵。
  多音字标虚线，点击选读音，选择随稿存档。
- **AI 评价**：两卷各一套 100 分制准则（设置页可改、可恢复默认）。乙编评审会随稿附上
  本地格律检测报告供模型复核。用典不单独占分（缺项裁决规则内置）。

## 怎么用

双击 `启动诗匣.bat`，浏览器自动打开 `http://localhost:8137`。关闭黑色窗口即停止。

- **模型接入**：设置页「＋ 新增模型配置」，填 OpenAI 兼容三项（接口地址 / API Key / 模型名），
  点「测试连接」。智谱、DeepSeek、Kimi、通义、GPT 等通用。
- **数据备份**：整个 `诗匣数据/` 文件夹拷走即是备份。字表在 `字表/`，词谱在 `词谱/`
  （加词牌 = 往词谱数据里加条目，不用改程序）。
- **拷到别的电脑**：`诗匣` 与 `诗匣数据` 两个文件夹并排拷过去即可，前提是那台电脑装了 Node.js。

## 数据与引擎

- 字表：平水韵 8436 字（含繁体全帙转简补全与手工核字）、词林正韵 8205、中华通韵 9017、
  中华新韵 6732，全部离线。
- 生僻字标注「无考」，不装懂；多音字不替你拍板。格律检测仅供参考，AI 评审被要求独立复核。
- `.build/` 是数据构建工具（含源数据与脚本），日常使用不需要动它。
- 回归测试：`node test-api.mjs`（API 29 项）、`node .build/test-gelv.js`（格律引擎 22 项），
  两者跑完都会清理测试数据。

## 分发给别人

双击 `打包分发.bat`，会在「现代诗」目录生成 **诗匣完整包-win-x64.zip**（约 34MB）。把这个 zip 发给任何人：

- 解压到任意位置，双击包根目录的 `启动诗匣.bat` 即用。
- 包内自带便携版 Node 运行时（`runtime/node.exe`），**对方不需要安装任何东西**，
  不联网也能用，不需要管理员权限。
- 若包内运行时不可用（极少数架构），启动器会自动从国内镜像下载对应版本（约 55MB，仅一次）。
- 包里的数据是干净的：不含你的诗稿，也**不含 config.json（你的 API Key 不会外泄）**。
- 如果想让对方直接带着你的诗稿，手动把 `诗匣数据/poems/`、`gushi/` 里的文件拷进包里再压缩即可
  （但不要把 config.json 给出去）。
